# AEROSPACE PEDIA — 항공우주 산업 백과사전

한국수출입은행(KEXIM) × Kearney "우주·항공산업 경쟁력 강화" 컨설팅 용역 온보딩용 백과사전입니다.
우주 픽셀아트 테마(로켓·셔틀·위성·전투기·여객기·UFO가 날아다니는 배경)의 단일 HTML입니다.

**7개 챕터, 135개 항목**
1. 미션 브리핑: 프로젝트 맥락 (수은 역할, 정책 배경, 예상 범위·워크스트림, 이해관계자, 킥오프 질문)
2. 항공우주 산업 101 (분류, 밸류체인·Tier, 인증, 프로그램 경제학)
3. 글로벌 시장과 플레이어
4. 대한민국 항공우주 (KAI, 한화, 우주항공청, 누리호, KF-21, 클러스터)
5. 정책금융 & 수출금융 (ECA, 항공기금융, OECD ASU, 방산 수출금융, 해외 ECA 벤치마킹)
6. 기술·프로그램 도감
7. 컨설턴트 툴킷 & 용어사전

- `index.html` / `항공우주_백과사전.html` — 완성본 (데이터 내장)
- `src.html` — 디자인/로직 원본, `data/*.js` — 챕터 데이터, `node build.js` — 재빌드
